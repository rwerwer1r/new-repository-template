# Repository guidance

- Confirm the repository owner and target branch before making changes; do not switch to another account.
- Follow the requirements and existing conventions of this repository rather than assuming a framework.
- Prefer scoped changes. Do not overwrite unrelated work, commit secrets, or execute unreviewed external scripts.
- Before a consequential write, confirm the intended target and authority where uncertain.
- Verify changed behavior using commands actually provided by the project; never invent successful test results.
- Report the affected files, verification outcome, and any limitations.
- Optional reusable guidance is listed in https://github.com/rwerwer1r/catalog; load only what the task requires.
